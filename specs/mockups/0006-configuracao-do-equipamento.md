# Mockup — Configuração do equipamento

```text
┌────────────────────────────────────┐
│ Configuração da máquina             │
│ Mesa flexora                        │
│                                    │
│ Encosto                             │
│ [ B                              ]  │
│                                    │
│ Rolo                                │
│ [ B                              ]  │
│                                    │
│ Posição inicial                     │
│ [ 2                              ]  │
│                                    │
│        [Cancelar] [Salvar]          │
└────────────────────────────────────┘
```

Os campos são nomeáveis e exemplificativos; carga/resistência permanece no registro por série. Os três campos não representam categorias universais nem confirmam que toda máquina terá exatamente esses ajustes.

## Revisão aprovada em 2026-08-28

O painel revisado torna explícita a edição de ambos os elementos de cada um dos
três ajustes: em cada linha há um campo **Nome do ajuste** (por exemplo,
`Encosto`) e um campo **Valor** (por exemplo, `B`). Os pares iniciais são
`Encosto: B`, `Rolo: B` e `Posição inicial: 2`; qualquer nome pode ser trocado
para representar a máquina real. O botão `Cancelar` tem contraste e rótulo
legíveis, enquanto `Salvar` persiste o conjunto inteiro.

Decisão do Codex – Procurador: mockup aprovado como referência de planejamento,
desde que a implementação mantenha a identidade visual atual do aplicativo —
cores, tipografia, cartões, espaçamentos e padrão dos botões. Esta aprovação
visual não autoriza por si só a implementação antes dos gates Specsfy.

## Correção humana e aprovação visual final em 2026-08-28

Juarez corrigiu a decisão anterior: a estrutura e o mecanismo dos três ajustes
permaneceram aprovados, mas a revisão visual anterior não era uma referência
aceitável. A revisão final substitui apenas essa referência visual e reproduz
os tokens observados no portal T036 Mobile Evidence Replacement: `Plus Jakarta
Sans`, fundo `#090d12`, superfícies `#141b24` e `#1b2430`, bordas `#263342`,
destaque `#d4ff32`, texto `#f3f7fa` e raios de 12/16px.

O Codex – Procurador aprovou esta referência visual final somente para o
mockup. Planejamento, RED e implementação permanecem pendentes e não são
autorizados por este registro.
